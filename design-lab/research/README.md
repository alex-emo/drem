# 研究摘录规则

> 这里的每一份文件都回答同一个问题：**这条原则能变成哪个像素或哪个毫秒？**

## 一条摘录必须包含

| 字段 | 要求 |
|---|---|
| 标题 | 原文标题，不改写 |
| URL | 可点击的原始地址 |
| 抓取日期 | `YYYY-MM-DD`，用系统时间 |
| 章节 | 原文中的小节名，便于复查 |
| 原文 | 英文原句，逐字照抄，1–3 句；用 `>` 引用块 |
| 直译 | 中文直译，保留语气，不做润色 |
| 我的解读 | 2–4 句：它解决什么认知/感知问题，为什么有效 |
| 对 Dream 的可用点 | 具体到位置、尺寸、时长、文案；不写“提升体验” |
| 不适用点 | 什么情况下这条原则会失效 |

## 可信度分级

- **A 级**：直接引用原文，且能在页面正文中定位到。
- **B 级**：只拿到摘要/二手转述，标注「转述」。
- **C 级**：凭记忆，不写入结论，只用于提出待验证的问题。

结论只能建立在 A/B 级材料上。C 级材料不得进入 `decisions/`。

## 一条好摘录的样子

> “Calm technology engages both the center and the periphery of our attention, and in fact moves back and forth between the two.”
>
> 直译：平静的技术同时占用注意力的中心与边缘，并在两者之间来回移动。
>
> 解读：提示若长时间占据中心，就不再“平静”；它应该先在边缘被看见，需要时再进入中心。

## 禁止

- 把几篇文章揉成一段没有出处的“行业共识”。
- 用“研究表明”代替具体研究。
- 只收藏链接、不抄原文。
- 为了支持已有方案而挑句子。
