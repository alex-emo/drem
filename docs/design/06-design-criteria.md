# 06 · 四个词的可操作定义

> v0.1 · 2026-11-25 · 回答「什么叫简约大方 / 小气抠搜廉价 / 流畅符合直觉 / 非人交互」。
> 原则：每个判断都落到可测量的量上，不写形容词。

## 1. 简约大方

不是「元素少」，是 **每个元素都有理由，留白承担结构**。

| 维度 | 做法 | 量化 |
| --- | --- | --- |
| 留白 | 让内容呼吸，而不是把屏幕塞满 | 页边距 20–24；段落间距 ≥12；行高 1.5–1.6 |
| 层级 | 一屏一个主任务，标题/正文/辅助三级 | 字号 34/16/12.5；字重 600/400；同屏强调色 ≤1 |
| 对齐 | 所有左边缘落在同一网格 | 4pt 网格；同类元素间距只用 4/8/12/16/20/24/32/48 |
| 克制 | 颜色、圆角、阴影有且只有一套 | 圆角 10/14/20；发丝线 1px；不叠阴影+描边+渐变 |
| 从容 | 触控区和文字一样从容 | 可点区域 ≥44×44；按钮高 ≥48 |

大方 = 尺度从容，不是面积大。微信读书、Notion、Linear、Things 的共同点：大留白、低对比分割线、极少装饰、排版承担大部分美感。

## 2. 小气抠搜廉价

不是「便宜」，是 **该花的地方省，不该花的地方乱花**。

- 该留白不给：padding 8、行高 1.2、文字贴边。
- 该克制不克制：每行卡片都带阴影，每个图标都上色，标题用渐变。
- 不一致：圆角 12/16/20 混用，按钮 40/48/56 混用，间距 6/10/14 混用。
- 用装饰补空洞：玻璃拟态、霓虹、粒子、无意义的呼吸动画——「假科技感」。
- 文案咋呼：「震撼」「颠覆」「AI 赋能」。
- 省成本省到体验上：无骨架屏、错误只写「失败」、删除无撤销。

## 3. 流畅符合直觉的交互

核心是 **因果、连续、可打断**，不是动画多。

| 原则 | 含义 | 量化 |
| --- | --- | --- |
| 跟手 | 手指到哪，界面到哪 | 拖拽位移 = 手指位移 ×1.0；左缘抽屉 44pt 起拖 |
| 惯性 | 松手后按速度继续，越界越拉越费力 | BouncingScrollPhysics + AlwaysScrollable；不手写 Simulation |
| 回弹 | 越界有阻尼，松手弹回 | 框架 rubberBandSpring；一次手势一次触觉，不按帧触发 |
| 可打断 | 动画中途可反向，不锁输入 | 转场中可点返回；动画期间输入框可用 |
| 连续 | 元素从触发处生长，不凭空出现 | 弹层从按钮/手指位置展开；页面转场 280ms |
| 时机 | 反馈要快，转场要短 | 按压 90ms；常规 150–300ms；退出 = 进入 ×0.8 |
| 一致 | 同一手势全 app 同一结果 | 左滑 = 返回/删；长按 = 语音/菜单；单击 = 主操作 |
| 冗余 | 视觉之外再给一层确认 | 关键动作 selection/medium 触觉；发送、删除、回弹 |

## 4. 非人交互

**要求人去适应机器**，而不是机器适应人。

- 隐藏手势且无提示，用户只能猜。
- 点了没反馈，或反馈晚于 100ms。
- 动画炫技且阻塞：必须看完才能操作。
- 控件位置漂移：每次进入都在不同位置。
- 误触惩罚重：删除无撤销，确认弹窗轰炸。
- 手势打架：输入框长按选词 vs 长按说话。
- 只用颜色/位置编码信息，无文字、无无障碍语义。
- 匀速机械运动，无缓动、无中断、无触觉。

## 5. 本项目的对照结论

| 之前 | 问题 | 现在 |
| --- | --- | --- |
| DreamMark 渐变 + 大模糊阴影 | 廉价「假科技感」，每帧开销高 | 纯色品牌蓝，零阴影 |
| 聊天页品牌渐变背景 | 装饰抢内容 | `theme.scaffoldBackgroundColor` 纯色 |
| 顶栏 4 个图标让用户瞄准 | 非人：要求用户辨认 | 左缘滑动开会话；深度思考/联网降为输入区小胶囊 |
| 语音要单独按按钮 | 多一步 | 输入框长按 420ms 说话，上滑 56pt 取消，松手发送 |
| 每条请求 `thinking:true` | 慢、贵、与「快」矛盾 | 默认关，需要时再开 |
| 流式时列表不跟底 | 用户要追着看 | 贴底跟随；离底 >240pt 出现「回到底部」 |
| 列表无回弹/阻尼 | 手感「死」 | 全局 Bouncing + AlwaysScrollable；顶部越界一次轻触 |

## 6. 复核清单（每次改 UI 前过一遍）

1. 这个元素删掉，信息或操作会丢吗？不会就删。
2. 左右边缘是否都落在 20pt 页边距内？
3. 同类元素圆角/间距/字号是否完全一致？
4. 有没有同时使用阴影、描边、渐变三种装饰？
5. 触控区是否 ≥44pt？文字对比度是否 ≥4.5:1？
6. 手势是否跟手、可打断、有触觉？
7. 动画是否 ≤300ms，且不阻塞操作？
8. 删除/清空是否有撤销或确认？
9. 错误是否说清「发生了什么、怎么办」？
10. 减少动效开启后，功能是否完全可用？
