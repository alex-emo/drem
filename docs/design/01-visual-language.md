# 01 · 视觉语言

## 1. 颜色

所有颜色必须来自 `Theme.of(context).colorScheme` 或 `DreamPalette`；feature 层禁止硬编码。

### 核心语义

| 角色 | Dark | Light | 用途 |
|---|---|---|---|
| canvas | `#101012` | `#FCFCFD` | 页面底 |
| sidebar / surfaceLow | `#161619` | `#F5F5F7` | 次级表面、错误态底 |
| elevated | `#1E1E22` | `#FFFFFF` | 弹层、浮起表面 |
| composer | `#131315` | `#FFFFFF` | 输入区 |
| border | `#26262B` | `#E7E7EC` | 结构线、禁用底 |
| borderStrong | `#35353C` | `#D8D9E0` | 次级按钮描边 |
| textPrimary | `#F4F4F5` | `#141416` | 正文、标题 |
| textSecondary | `#B9BCC3` | `#575A61` | 副标题、说明 |
| textTertiary | `#7F838C` | `#6C7079` | 元信息、占位（浅色对比 4.84:1，最差面 4.56:1；见 design-lab/decisions/0003） |
| brand | `#5686FE` | `#3964FE` | 主动作、焦点、选中 |
| brandSoft | brand @16% | brand @9% | 选中底、轻提示 |
| danger | `#E5645C` | `#E5645C` | 错误、破坏性 |
| warning | `#E2A03F` | `#E2A03F` | 警告 |
| success | `#4FB477` | `#4FB477` | 成功 |
| bubbleUser | `#1B2233` | `#EEF2FE` | 用户消息底 |

### 使用规则

- 品牌蓝一屏最多出现 3 处高饱和用法；其余用 `brandSoft`。
- 不用纯黑 `#000` / 纯白 `#FFF` 作为大面积正文底；用上表。
- 用户气泡是低饱和蓝灰，不是品牌蓝实心；助手消息不套气泡。
- 分割线只用在结构分组；不要给每行都加线。
- 渐变只允许一种：页面左上角极轻的品牌环境光（alpha ≤ 0.08），且不承载信息。

## 2. 字体

系统字体（SF Pro / Roboto），中文走系统回退。字号 token：

| Token | Size | Weight | Height | 用途 |
|---|---|---|---|---|
| displaySmall | 34 / 30（compact） | 600 | 1.12 | 空态主标题 |
| headlineMedium | 26 | 600 | 1.22 | 页面大标题 |
| headlineSmall | 22 | 600 | 1.25 | 区块标题 |
| titleLarge | 19 | 600 | 1.3 | 顶栏品牌、页面标题 |
| titleMedium | 16 | 600 | 1.4 | 列表项标题 |
| bodyLarge | 16 | 400 | 1.55 | 正文、消息 |
| bodyMedium | 14 | 400 | 1.5 | 说明 |
| bodySmall | 12.5 | 400 | 1.45 | 元信息 |
| labelLarge | 14 | 500 | 1.3 | 按钮 |
| labelMedium | 12 | 500 | 1.3 | 标签、编号 |

规则：

- 字重只用 400 / 500 / 600；不用 300 / 700+（空态标题可 600）。
- 标题字距 -0.4 ~ -1.0；正文 0；全大写标签 +1.2。
- 正文最小 12.5；不使用 10–11 的“设计感小字”。
- 支持 Dynamic Type；文本放大 2.0 时布局不截断关键操作。

## 3. 间距与网格

- 基线 4pt；主节奏 8pt。
- token：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48`。
- 页面水平边距：compact 20，wide 28；聊天内容最大宽度 780。
- 顶栏高度 56（不含安全区）；输入区最小 56 + 安全区。
- 列表行垂直 padding 14–17；建议行之间用 1px 结构线。
- 不使用负 margin；不做重叠卡片。

## 4. 圆角、描边、阴影

| Token | 值 | 用途 |
|---|---|---|
| sm | 10 | 小控件、选中底 |
| md | 14 | 输入、按钮、提示 |
| lg | 20 | 弹层内卡片、错误态 |
| xl | 28 | bottom sheet 顶角 |
| pill | 999 | 标签、胶囊按钮 |

- 结构线 1px；不用 2px 以上描边（焦点态可用 1.5）。
- 默认无阴影。允许：品牌 mark 的柔光、bottom sheet 的系统阴影。
- 禁止：卡片投影、彩色发光、玻璃模糊堆叠。

## 5. 图标

- Material Rounded 线性图标；尺寸 18 / 20 / 22。
- 图标颜色跟文本层级；不要彩色图标（错误/成功除外）。
- 图标按钮视觉 20–22，触控区 ≥44；输入区麦克风/发送/录音按钮 ≥48。
- 不用 emoji 当图标；不用品牌 logo 当功能图标。

## 6. 布局与响应式

三段式：

```text
[ safe area ]
[ top bar 56                 ]
[ content (scroll, max 780)  ]
[ composer + safe area       ]
```

- < 360：水平边距 20；标题 30；建议行副标题可省略。
- 360–600：标准手机布局；标题 30–34。
- > 600：内容居中，最大 780；左右留白，不放大字号。
- 横屏：内容仍单列；键盘弹起时输入区贴底，消息区可滚动。
- 平板：不做双栏；未来会话列表用 drawer，不与内容并排挤压。

## 7. 深色 / 浅色

- 深色优先；浅色同等完成度，不是反色。
- 浅色背景用 `#FCFCFD`，不要纯白大面积；深色用 `#101012`，不要纯黑。
- 两套主题共用同一 token 名；feature 不写 `if (dark)`。
- 主题切换 280ms 过渡；减少动效时立即切换。

## 8. 可访问性

- 正文对比度 ≥ 4.5:1；大字号 ≥ 3:1。
- 可点击目标 ≥ 44×44（Material 主操作 48×48，见 `design-lab/research/02-omd-feel-audit.md`）；相邻目标间距 ≥ 8。
- 所有图标按钮有 `tooltip` / `Semantics(label)`。
- 流式文本用 `liveRegion` 谨慎播报；不要逐字打断读屏。
- 支持减少动效、粗体文本、横屏、动态字体。
