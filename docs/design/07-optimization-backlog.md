# 07 · 设计优化清单（Backlog）

> v0.1 · 2026-11-25 · 基于当前 Flutter 客户端截图、手势实现与外部资料整理。
> 原则：只列能验收的改动；每条都有「问题 → 做法 → 验收」。

## 0. 现状审计（截图与代码）

- 顶栏已收敛为 2 个可点入口（菜单/新对话，2026-11-25），深度/联网在输入区上方。
- 输入区已有常驻麦克风（48×48，发送键左侧、不随发送键位移），轻点录音、覆盖条有计时 + 取消 + 停止，60 秒自动停止；未聚焦时长按输入行保留为加速器；转写后可撤销/重试（2026-11-25 完成，见 P0-6 与 `design-lab/decisions/0006-voice-entry-v2.md`）。
- 消息操作（复制/编辑/重新生成）只在长按菜单里，无任何可发现性提示，且还没有引用/分支/精确时间。
- 日期分隔已按天插入（2026-11-25，见 P0-5）；精确时间仍未在界面上出现，「新消息」标记也没有。
- 会话抽屉只有列表与删除，没有搜索/置顶/重命名。
- 会话抽屉的入口问题已解决（顶栏菜单按钮，见 P0-1）；抽屉内容仍是「新对话 + 列表 + 设置」，缺搜索/置顶/重命名。
- 空态只有 4 条建议，没有「继续上次」。
- 设置页是纵向长列表，危险操作与普通设置混在一起。
- 性能：列表已用 RepaintBoundary 与 markdown 缓存，但整页 `setState` 仍会重建顶栏/输入区。

## P0 · 先做（低风险、直接改善手感）

### 1. 会话入口可见化（已替代「一次性手势引导」，2026-11-25 完成）
- 问题：隐藏手势没有可发现性，新用户不知道能左滑；更严重的是会话抽屉没有可见入口（顶栏只有一行不可点灰字「左滑会话」）。
- 原做法（已废弃）：首次进入显示 12px 提示「左滑看会话 · 长按说话」，3 秒淡出。废弃原因：用文案补控件，一次教两个动作，且 4 秒后线索永久消失；见 `design-lab/decisions/0001-session-drawer-affordance.md`。
- 现做法：顶栏左侧 44×44 菜单按钮打开抽屉，左缘 44pt 右滑保留为加速器；删除首屏横幅。
- 验收：菜单按钮可点开抽屉；`flutter test` 覆盖；无控制器时不显示菜单。

### 2. 顶栏减到两个可点入口（2026-11-25 完成）
- 问题：列表/搜索/深度/联网四个图标让用户瞄准；真实聊天页又走到另一个极端——一个都没有。
- 做法：左菜单（抽屉）+ 右「新对话」；设置、搜索留在抽屉，深度/联网保留下方胶囊。品牌不可点。
- 验收：顶栏可点元素 = 2；所有功能仍可达；widget 测试覆盖（`test/chat_header_test.dart`）。

### 3. 消息操作改为「长按 + 底部动作条」
- 问题：长按弹菜单遮挡消息，且选项无层级。
- 做法：长按消息 → 轻微缩放 + medium 触觉 → 底部动作条（复制/引用/编辑/重答/分支），当前消息高亮；点空白或下滑关闭；动作条高度 ≤ 64。
- 验收：长按 300ms 内出现；关闭后滚动位置不变；复制有「已复制」轻提示。

### 4. 会话抽屉补齐三件事
- 问题：只有列表和删除，找不到旧会话。
- 做法：顶部搜索框（本地标题/消息全文，防抖 200ms）；左滑删除、右滑置顶；长按重命名。空结果显示「没有匹配的会话」。
- 验收：100 条会话下搜索 <100ms；置顶排序稳定；删除有确认或撤销。

### 5. 时间锚点（2026-11-25 完成，只按天）
- 问题：长会话不知道哪天说的。
- 做法：只在本地日界插入日期分隔（今天/昨天/11月20日/2025年11月20日），首条不插、单日零分隔；分隔作为消息 item 的前置节点，不新增 ListView item。精确时间留给下一轮的长按动作条，不采用 5 分钟阈值（AI 对话一轮常超过 5 分钟，会退化成噪音；见 `design-lab/decisions/0002-day-anchors.md`）。
- 验收：跨天出现分隔、同日不产生噪音；`test/day_divider_test.dart` 覆盖。

### 6. 语音入口常驻化（2026-11-25 完成，v2 修订 0005）
- 问题：语音只有「未聚焦时长按输入行」一条隐藏路径；聚焦编辑时连这条也不可用，且录音中没有停止/取消以外的决定点。
- 做法（v2）：麦克风 48×48 **固定**在发送键左侧，空输入实心、有文字描边，不随发送键位移；发送键 48×48 独立槽位（空输入透明占位）。轻点录音（键盘不收起，同 iOS 听写），覆盖条「正在录音 + 计时 + × + ■」，两态一致；60 秒上限自动停止；转写填入输入框 + 5 秒「已转写 · 撤销」；失败可重试，空结果不写入。未聚焦长按输入行仍是加速器。见 `design-lab/decisions/0006-voice-entry-v2.md`（C 研究推翻 0005 的互换方案）。
- 验收：`test/composer_voice_test.dart` 7 条（常驻、占位不可点、录音/停止/取消、60 秒上限、失败退出、语音不可用）；`test/composer_gesture_test.dart` 4 条仍绿。

### 7. 空态「继续上次」
- 问题：空态只有建议，没有回到未完成对话的路径。
- 做法：最近 3 个会话以单行列表放在建议上方，点击直接进入；没有会话时只显示建议。
- 验收：有历史时可见；点击进入正确会话；无历史不占位。

## P1 · 手感与结构

### 8. 引用与分支一等公民
- 选中文本 → 浮动「引用」；引用块显示在输入区上方，可删除；发送后消息带 quote 元数据。分支切换器已有，补「从这条继续」入口。

### 9. 附件托盘
- 点「+」从底部升起托盘（拍照/相册/文件），拖动跟手、下滑关闭；上传进度显示在附件 chip 上；失败可重试。

### 10. 图片查看器
- 点图 → Hero 放大，双指缩放，下滑关闭（跟手 + 速度判定）；关闭回原位置。

### 11. 设置重组
- 分组：账号 / 外观 / 交互 / 数据 / 关于。清空数据、退出登录放到最底部，红色文字 + 二次确认；清空后给「撤销」或明确不可恢复提示。

### 12. 键盘与安全区
- 输入区跟随键盘，不遮挡最后一条消息；键盘弹起时若贴底则保持贴底；横屏不塌。

### 13. 无障碍
- 所有图标按钮有 `Semantics(label)`；正文支持系统字号放大到 1.3× 不截断；对比度 ≥4.5:1；减少动效开启后无位移/缩放。

## P3 · 审计遗留（omd:feel，2026-11-25）

来源：`design-lab/research/02-omd-feel-audit.md`。这些项有规范依据，但一次性改动面大或需要真机目测，单独排。

- **排版基线**：正文行高 24.8/21/18.125、气泡 26.73 均不在 4px 网格；字号阶梯也不在 1.2–1.333。需要一次 0007 排版决策（先定字号，再定行高，同屏对比）。
- **动效阶梯**：`DreamMotion` 全部不在 50ms 网格；`page/pageOut` 比例 0.79 合规但值不整。需要一次 0008（阶梯取 100/150/200/250/300 + 循环 token 单列），改前在动效页与真机录屏确认。
- **顶栏 44 vs 48**：顶栏按钮 44×44 达 Apple/AAA，未达 Material 48；56pt 顶栏下改 48 会挤压品牌，记录为已知偏差。
- **录音剩余时间**：只有 `0:07` 文本，没有最后 5 秒的视觉警示。
- **首次提示**：「点按说话」与「长按输入行」两条提示未合并设计，暂不做。
- 平板/折叠屏双栏（列表 + 对话）。
- 生成完成的后台通知与角标。
- 列表首屏 stagger 只播一次；后续进入不加动画。

## 性能与成本

| 项 | 做法 | 目标 |
| --- | --- | --- |
| 重建范围 | 顶栏/输入区拆成独立 `ValueListenableBuilder`，消息列表只重建变化项 | 流式时非消息区 0 重建 |
| 帧率 | 避免 `saveLayer`、`BackdropFilter`、大阴影；图片 `cacheWidth`；长列表 `itemExtent` 不适用则 `RepaintBoundary` | janky <1% |
| 首帧 | 减少启动时同步 IO；数据库/预加载放到首帧后；Impeller 保留 | 冷启动 <1.5s（当前 361–561ms） |
| 包体 | `--split-per-abi`、图标 tree-shake、release 不含 debug 符号 | arm64 ≤20MB |
| 流式 | 30ms 批量 tick；markdown LRU；贴底用 jumpTo 不用动画 | 首字 <100ms 感知 |

## 验收方式

1. `flutter analyze` 0 error；`flutter test` 全绿。
2. 真机：冷启动 3 次取中位数；滚动 10 秒读 `dumpsys gfxinfo` 的 janky 比例。
3. 手势：左缘 44pt 起拖成功率、长按 420ms 触发率、上滑 56pt 取消率，各手动 10 次。
4. 无障碍：TalkBack 走查主要路径；系统字号 1.3× 截图。
5. 视觉：深浅色各一张截图，对照 01 文档的间距/圆角/字号表。
