# 07 · 设计优化清单（Backlog）

> v0.1 · 2026-11-25 · 基于当前 Flutter 客户端截图、手势实现与外部资料整理。
> 原则：只列能验收的改动；每条都有「问题 → 做法 → 验收」。

## 0. 现状审计（截图与代码）

- 顶栏仍有 4 个入口（列表/搜索/深度/联网），其中列表已可左缘滑出，属于重复入口。
- 输入区右侧仍有独立麦克风按钮，和「长按说话」重复。
- 消息操作（复制/编辑/重答/分支）只在长按菜单里，无任何可发现性提示。
- 消息之间没有日期分隔、没有「新消息」标记，长会话里缺少时间锚点。
- 会话抽屉只有列表与删除，没有搜索/置顶/重命名。
- 首次进入没有手势引导；长按说话、左缘抽屉、上滑取消全靠猜。
- 空态只有 4 条建议，没有「继续上次」。
- 设置页是纵向长列表，危险操作与普通设置混在一起。
- 性能：列表已用 RepaintBoundary 与 markdown 缓存，但整页 `setState` 仍会重建顶栏/输入区。

## P0 · 先做（低风险、直接改善手感）

### 1. 一次性手势引导
- 问题：隐藏手势没有可发现性，新用户不知道能左滑、能长按。
- 做法：首次进入聊天页，在输入区上方显示一条 12px 提示「左滑看会话 · 长按说话」，3 秒后淡出；首次成功手势后写入 `dream-gesture-hint-seen`，不再出现。不做全屏蒙层。
- 验收：新装首次可见；完成任一手势后不再出现；不阻塞输入。

### 2. 顶栏减到 1 个入口
- 问题：列表/搜索/深度/联网四个图标让用户瞄准。
- 做法：删除列表图标（左缘手势已覆盖）；搜索进入会话抽屉顶部；深度/联网保留下方胶囊。顶栏只留品牌与「新对话」。
- 验收：顶栏可点元素 ≤2；所有功能仍可达；widget 测试覆盖。

### 3. 消息操作改为「长按 + 底部动作条」
- 问题：长按弹菜单遮挡消息，且选项无层级。
- 做法：长按消息 → 轻微缩放 + medium 触觉 → 底部动作条（复制/引用/编辑/重答/分支），当前消息高亮；点空白或下滑关闭；动作条高度 ≤ 64。
- 验收：长按 300ms 内出现；关闭后滚动位置不变；复制有「已复制」轻提示。

### 4. 会话抽屉补齐三件事
- 问题：只有列表和删除，找不到旧会话。
- 做法：顶部搜索框（本地标题/消息全文，防抖 200ms）；左滑删除、右滑置顶；长按重命名。空结果显示「没有匹配的会话」。
- 验收：100 条会话下搜索 <100ms；置顶排序稳定；删除有确认或撤销。

### 5. 时间锚点
- 问题：长会话不知道哪天说的。
- 做法：相邻消息间隔 >30 分钟插入日期/时间分隔（今天/昨天/MM-DD），12px 三级文字，居中；流式消息不重复插入。
- 验收：跨天会话出现分隔；同日连续消息不产生噪音。

### 6. 空态「继续上次」
- 问题：空态只有建议，没有回到未完成对话的路径。
- 做法：最近 3 个会话以单行列表放在建议上方，点击直接进入；没有会话时只显示建议。
- 验收：有历史时可见；点击进入正确会话；无历史不占位。

## P1 · 手感与结构

### 7. 引用与分支一等公民
- 选中文本 → 浮动「引用」；引用块显示在输入区上方，可删除；发送后消息带 quote 元数据。分支切换器已有，补「从这条继续」入口。

### 8. 附件托盘
- 点「+」从底部升起托盘（拍照/相册/文件），拖动跟手、下滑关闭；上传进度显示在附件 chip 上；失败可重试。

### 9. 图片查看器
- 点图 → Hero 放大，双指缩放，下滑关闭（跟手 + 速度判定）；关闭回原位置。

### 10. 设置重组
- 分组：账号 / 外观 / 交互 / 数据 / 关于。清空数据、退出登录放到最底部，红色文字 + 二次确认；清空后给「撤销」或明确不可恢复提示。

### 11. 键盘与安全区
- 输入区跟随键盘，不遮挡最后一条消息；键盘弹起时若贴底则保持贴底；横屏不塌。

### 12. 无障碍
- 所有图标按钮有 `Semantics(label)`；正文支持系统字号放大到 1.3× 不截断；对比度 ≥4.5:1；减少动效开启后无位移/缩放。

## P2 · 后续

- 本地全文搜索（FTS5 或内存索引）。
- 多选/批量删除 + 撤销。
- 会话分享为图片卡片。
- 平板/折叠屏双栏（列表 + 对话）。
- 生成完成的后台通知与角标。
- 列表首屏 stagger 只播一次；后续进入不加动画。

## 性能与成本

| 项 | 做法 | 目标 |
| --- | --- | --- |
| 重建范围 | 顶栏/输入区拆成独立 `ValueListenableBuilder`，消息列表只重建变化项 | 流式时非消息区 0 重建 |
| 帧率 | 避免 `saveLayer`、`BackdropFilter`、大阴影；图片 `cacheWidth`；长列表 `itemExtent` 不适用则 `RepaintBoundary` | janky <1% |
| 首帧 | 减少启动时同步 IO；数据库/预加载放到首帧后；Impeller 保留 | 冷启动 <1.5s（当前 361–561ms） |
| 包体 | `--split-per-abi`、图标 tree-shake、release 不含 debug 符号 | arm64 ≤20MB |
| 流式 | 30ms 批量 tick；markdown LRU；贴底用 jumpTo 不用动画 | 首字 <100ms 感知 |

## 验收方式

1. `flutter analyze` 0 error；`flutter test` 全绿。
2. 真机：冷启动 3 次取中位数；滚动 10 秒读 `dumpsys gfxinfo` 的 janky 比例。
3. 手势：左缘 44pt 起拖成功率、长按 420ms 触发率、上滑 56pt 取消率，各手动 10 次。
4. 无障碍：TalkBack 走查主要路径；系统字号 1.3× 截图。
5. 视觉：深浅色各一张截图，对照 01 文档的间距/圆角/字号表。
