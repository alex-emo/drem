# 组件规格 · Motion Lab（动效实验室）

Owner: settings-motion · 开发用，不进发布

## 1. 目标

给设计/开发一个可交互的动效与组件验收台，让每个 token 都能被看见和点按，而不是只在代码里。

## 2. 分区

```text
按压反馈        PressableScale 示例（scale 0.97 / 120ms）
气泡进入        用户 + 助手气泡，触发 260ms 进入
弹层            触发 bottom sheet（系统）
错误态          ErrorView 示例 + 重试
主题            DreamPalette 两套切换按钮
流式光标        呼吸光标预览
```

- 每区一个标题 + 一个可触发控件，触发后显示对应效果。
- 顶部开关：“减少动效”全局切换（用 `MediaQuery` 覆盖），便于验收 02 的关闭路径。
- 复用 T1/T2 组件，不另写一套。

## 3. 验收

- 各区控件可触发且效果可见。
- 减少动效开关打开后，位移/缩放/呼吸消失，状态仍可达。
- 深/浅主题下预览正常。
