# 组件规格 · Composer（输入区）

Owner: composer-messages

## 1. 目标

“输入是权力面”：一个多行、专注、反馈明确的输入区。只暴露当下能用的能力。

## 2. 结构

```text
[ 发丝线分隔 1px border ]
[ 附件按钮 44 ] [ TextField 多行（含长按说话手势） ] [ 麦克风 48 ] [ 发送 48 ]
[ 安全区 ]
```

长按手势只挂在 TextField 所在的 `Expanded` 上，不覆盖附件与右侧按钮（避免「按住发送键 420ms 开始录音」）。**麦克风常驻在自己的槽位**，发送键独立排在它右边；发送键出现/消失时麦克风不位移。见 `design-lab/decisions/0006-voice-entry-v2.md`（修订 0005 的互换方案）。

- 无卡片、无渐变、无底部一排开关。
- 附件按钮是 P1 占位（点击给明确提示）。

## 3. 行为

- 多行自动增高：1 行起，最多 5 行；超过 5 行 TextField 内部滚动。
- 聚焦：容器边框 border→brand（1.5px，180ms）；失焦恢复。
- 发送：`onSend(text)` 后清空并保持焦点；输入为空时发送禁用。
- 回车：软键盘回车换行；移动端不发送。
- 附件：点击 `onAttach`，P0 显示“附件将在 P1 接入”。
- 语音入口：`voiceEnabled` 为真时，麦克风 48×48 常驻在发送键左侧。输入为空时是品牌实心圆（白色 `mic_none_rounded` 24、tooltip「语音输入」）；有文字时退成描边圆（透明底 + border + textSecondary 图标），但仍可点。
- 发送键 48×48 常驻槽位：空输入时 `AnimatedOpacity` 到 0 且 `IgnorePointer`，不响应点击；有文字时淡入品牌实心圆。
- 轻点麦克风：进入录音，键盘不收起（同 iOS 听写）；覆盖条「红点 + 正在录音 + 计时 + × 取消 + ■ 停止」。停止 = `onVoiceEnd(false)` → 转写填入输入框、聚焦、不自动发送；取消 = `onVoiceEnd(true)` → 丢弃。
- 上限 60 秒：`_ticker` 到点自动停止并转写（不静默丢弃）。
- 转写后：输入框内容 + SnackBar「已转写 · 撤销」5 秒；撤销恢复转写前文本。失败有音频时「重试」；空结果提示「没听清，请再说一次」，不写入。
- 长按说话（加速器）：输入框**未聚焦**时，按住 420ms 进入录音（轻点仍是聚焦输入）；已聚焦时按住属于选字/移动光标，不进入录音。移动超过 12pt 取消计时，录音中上滑超过 56pt 标记取消并触觉反馈；松手停止录音，转写结果填进输入框（不直接发送，由用户确认后发送）。长按录音态也显示 × 取消与 ■ 停止（第二根手指可点；WCAG 2.5.1 的非路径退路）。
- 失败退出：`onVoiceStart` 返回 `false`（无权限等）时立刻退出聆听态，不留假录音；错误提示由聊天页负责。

## 4. 状态

- 空（麦克风实心 + 发送透明占位）
- 有内容（麦克风描边、发送 brand）
- 聚焦 / 失焦（聚焦时长按=选字，不录音）
- 录音中（两态共用覆盖条：正在录音 + 计时 + 取消/停止；上滑时文案变「松开取消」）
- 转写后（已转写 · 撤销）
- 禁用 / 深色 / 浅色 / 减少动效 / 大字号

## 5. 无障碍

- 附件 44×44；麦克风、发送、取消、停止均 48×48（Material 3 交互目标），带 tooltip（语音输入 / 取消录音 / 停止录音）。
- TextField 有 `semanticsLabel`（“消息输入框”）。
- 发送禁用态仍可聚焦但不可点；读屏能读到禁用。

## 6. 验收（单测）

- 空输入 `canSend=false`，输入后 `canSend=true`。
- 多行到 5 行后不再增高，内部滚动。
- 发送回调收到当前文本，发送后输入清空。
- 聚焦/失焦回调触发；减少动效下仍可用。
- 已聚焦时长按不触发 `onVoiceStart`；按住发送按钮不触发 `onVoiceStart`；未聚焦时长按仍能录音、上滑取消（`test/composer_gesture_test.dart`）。
- 麦克风常驻、发送键空输入时占位不可点；有文字时麦克风仍在；点麦克风进入录音且焦点不丢；停止结算 `cancel=false` 且不自动发送；取消结算 `cancel=true` 且输入不变；60 秒上限自动停止；开始失败不留假聆听态；`voiceEnabled=false` 时没有麦克风（`test/composer_voice_test.dart`）。
